# Épico: Landing Page

O épico **Landing Page** tem como objetivo apresentar o propósito do projeto de forma clara e atrativa, servindo como porta de entrada para os visitantes. A página deve contextualizar o site, destacando sua relevância cultural e educacional, além de oferecer uma navegação intuitiva para explorar o mapa das edificações.

---

## US08 - Visualizar landing page do projeto

**Como** visitante
**Quero** acessar a landing page do projeto
**Para** entender o propósito do site antes de explorar o mapa das edificações.

**Critérios de Aceitação**

- A landing page deve ser acessível pela URL principal do site
- A página deve apresentar:
    - título do projeto
    - descrição/contextualização basica
- A página deve possuir layout responsivo

## US09 - Acessar seção sobre imigração alemã

**Como** visitante
**Quero** visualizar uma seção explicando a história da imigração alemã
**Para** compreender o contexto cultural relacionado ao projeto.

**Critérios de Aceitação**

- A landing page deve possuir uma seção sobre imigração alemã
- A seção deve apresentar:
    - título
    - texto explicativo
    - imagens ilustrativas se possivel

## US10 - Visualizar biografia do arquiteto

**Como** visitante
**Quero** visualizar informações sobre o arquiteto Theodor Wiederspahn
**Para** entender sua importância histórica e arquitetônica.

**Critérios de Aceitação**

- Deve existir uma seção dedicada ao arquiteto
- A seção deve apresentar:
    - nome do arquiteto
    - biografia resumida
    - imagem do arquiteto (se disponível)

## US11 - Acessar o mapa interativo a partir da landing page

**Como** visitante
**Quero** acessar o mapa interativo do projeto
**Para** explorar as edificações diretamente no mapa.

**Critérios de Aceitação**

- A landing page deve possuir um botão ou link para o mapa
- O link deve direcionar para a página do mapa
- O botão deve estar visível na página inicial

## US12 - Visualizar links institucionais relacionados

**Como** visitante
**Quero** acessar links institucionais relacionados ao projeto
**Para** consultar informações adicionais em sites oficiais.

**Critérios de Aceitação**

- A landing page deve exibir links institucionais
- Cada link deve apresentar:
    - título
    - destino clicável
- Os links devem abrir corretamente

## US13 - Navegar pela landing page com acessibilidade básica

**Como** visitante com necessidades de acessibilidade
**Quero** navegar pela landing page com recursos acessíveis
**Para** conseguir consumir o conteúdo sem barreiras.

**Critérios de Aceitação**

- Imagens devem possuir texto alternativo
- Estrutura semântica adequada para leitores de tela
- Navegação possível via teclado
- Contraste adequado entre texto e fundo
