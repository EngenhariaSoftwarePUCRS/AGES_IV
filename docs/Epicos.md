# Épicos - Regras Globais

Este documento consolida regras gerais que se aplicam a todos os épicos.

## Acessibilidade (A11y)

- O site deve possuir contraste adequado entre texto e fundo.
- Todos os conteúdos visuais devem possuir alternativas textuais quando possível.
- A navegação deve ser possível utilizando teclado para as funções principais.
- Elementos interativos devem possuir identificação adequada para leitores de tela.
- Sempre que possível, conteúdos multimídia devem possuir descrição textual ou equivalente.
- A interface deve evitar dependência exclusiva de cores para transmitir informação.

## Internacionalização (i18n)

- O sistema deve permitir alternar entre os idiomas: Português, Alemão e Inglês.
- O idioma selecionado deve atualizar todo o conteúdo textual disponível.
- O idioma selecionado deve permanecer ativo durante toda a navegação do usuário e ser armazenado para visitas futuras.
- O idioma deve ser detectado automaticamente com base nas preferências do navegador, mas o usuário deve poder alterar manualmente.
- Elementos de interface devem indicar claramente o idioma selecionado.

## Regras Gerais

- As principais interfaces devem ser responsivas e compatíveis com desktop e dispositivos móveis.
- Funcionalidades centrais devem preservar desempenho aceitável em redes móveis comuns.
- Registros e coletas de dados não devem impactar negativamente o tempo de carregamento das páginas.
